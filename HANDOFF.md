# Handoff — передача контекста между сессиями

---

## Последняя сессия: 2026-03-04

### Что сделали

**1. Полный рефакторинг пайплайна (v3) — `modules/timeline.py`, `modules/llm_analyzer.py`, `main.py`, `modules/renderer.py`, `config.py`**
- Удалён двойной порог (PHRASE_SPLIT_SEC=1.5 + PAUSE_CUT_SEC=0.6) → один порог 0.6с
- `build_blocks()`: все слова Whisper → блоки по паузам ≥ 0.6с + буфер 0.2с
- LLM получает все блоки сразу, возвращает `{"delete": [indices]}` — простой формат
- Kept-блоки = готовый таймлайн, идут напрямую в renderer

**2. Улучшение промпта LLM — `modules/llm_analyzer.py`**
- Добавлены 5 категорий удаления: повторы, запинки, техповторы, осколки, обрезанные слова
- Категория 4 (ОСКОЛКИ): короткий блок между двумя удалёнными блоками → тоже удалять
  - Пример: удалены [3] и [6], блок [5] "дизайн с ИИ" — осколок
- Категория 5 (ОБРЕЗАННЫЕ СЛОВА): блок начинается с несуществующего слова ("фовую" вместо "кайфовую")
- Убрано ограничение "несколько раз подряд" → повторы через 1-3 блока тоже ловятся

**3. Автоудаление осколков в коде — `_cleanup_orphan_fragments()`**
- После LLM-ответа: если оба соседа блока удалены И блок ≤5 слов или <2.5с → авто-удаление
- Резервная защита если LLM промпт не поймал
- Лог: `авто-удалён (осколок): 'дизайн с ИИ'`

**4. Whisper large-v3 с ленивой загрузкой — `modules/transcriber.py`, `config.py`**
- `WHISPER_MODEL = "large-v3"` (было medium)
- Модель загружается только при старте транскрипции (`_load_model`)
- После транскрипции выгружается (`del self._model` + `gc.collect()`)
- RAM в простое: ~0 (было ~1.5GB постоянно)

**5. Swap на сервере**
- Добавлен `/swapfile` 4GB (был 0 swap)
- Причина: large-v3 в пике ест ~6GB → OOM killer убивал процесс
- Теперь: 5.8GB RAM + 4GB swap = 9.8GB эффективно

**6. Команды `/morning` и `/endday` — `.claude/commands/`**
- `.claude/commands/morning.md` — читает HANDOFF.md + CLAUDE.md, план на день
- `.claude/commands/endday.md` — перезаписывает HANDOFF.md

### Статус деплоя
Всё задеплоено, бот активен. Последние коммиты:

## Обещания / договорённости

- **Не держать Whisper в памяти постоянно** — ленивая загрузка, модель живёт только во время транскрипции
- **Один порог 0.6с** для всего — не возвращать двойной порог
- **`_PRE_ROLL_SEC = 0.0`** — не менять, pre-roll управляется только через `PAUSE_BUFFER_SEC` в config
- **Swap не удалять** — он нужен для large-v3
