## Последняя сессия: 2026-06-28

### Что сделали
- **Выбор формата на выходе (vertical / horizontal)** — полная реализация во всех 4 файлах
- **session_manager.py**: `scan_sessions()` больше не требует вебку — достаточно файлов экрана. `concat_files()` возвращает `(Path, Optional[Path])`. `is_processed()` проверяет оба формата.
- **renderer.py**: `render_horizontal()` теперь принимает `webcam_file=None`. Новые методы `_render_single_input()`, `_render_chunk_single()`, фильтр `_screen_only_filter()` — рендер без вебки (кроп 1920×1080).
- **main.py**: `_pipeline()` принимает `output_format` ("vertical"/"horizontal"), вызывает нужный рендер.
- **bot.py**: после выбора сессии → экран выбора формата (📱 9:16 / 🖥 16:9). Вертикальный показывается только если есть вебка. Очередь хранит `(Session, format)` кортежи. «Запустить все» автоматически выбирает формат по наличию вебки.
